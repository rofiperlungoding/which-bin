Endpoints

EndpointReturns
GET/api/which-bin?item=&city=
class, bin, quote, verified, source. class is null when the page is silent.
GET/api/cities
Every city with its sources, rules (quote and URL) and gaps, plus the item list.
GET/api/stats
Benchmark headline numbers and the model audit.
POST/api/identify
Body: an image data URL. Returns {"item": "…"}.

Classes: recycle, organics, trash, special (drop-off, take-back, deposit or hazardous collection). Errors: 400 bad input, 404 city not on file, 429 busy, 502 model failure.

The public demo shares one small free quota (about 20 model calls a minute in total). For real traffic, self-host: the server is one file of standard-library Python.

MCP server

Gives Claude, or any MCP client, two tools: which_bin(item, city) and list_cities().

git clone https://github.com/rofiperlungoding/which-bin && cd which-bin
python fetch.py
claude mcp add which-bin -e GW_URL=... -e GW_KEY=... -- python mcp_server.py

GW_URL is any OpenAI-compatible /chat/completions endpoint and GW_KEY its key.

Self-host the site and API

GW_URL=... GW_KEY=... PORT=8000 python app.py

Add a city

Add rows to data/rules.csv: city, country, item, class, local stream name, a verbatim quote and the official URL. python bench.py stats checks the class, duplicates and the URL. Then python fetch.py saves the page for the checker.
